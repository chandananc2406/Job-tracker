# 🎯 AI-Powered Job Application Tracker

A Full Stack web application to track job applications with AI-powered resume feedback.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Security, Hibernate, MySQL
- **Frontend:** React JS
- **AI:** Google Gemini AI API
- **Tools:** Postman, Git, Maven

## ✨ Features
- Register and login users
- Add, view, update and delete job applications
- Track application status (Applied, Interview, Offered, Rejected)
- AI-powered resume feedback using Gemini AI

## 🚀 How to Run

### Backend
1. Import the `job-tracker` Maven project in Eclipse
2. Update `application.properties` with your MySQL credentials
3. Run as Spring Boot App

### Frontend
1. Navigate to `job-tracker-frontend` folder
2. Run `npm install`
3. Run `npm start`
